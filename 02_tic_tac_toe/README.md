# Tic-Tac-Toe (Minimax)

## Algorithm
Adversarial search with **Minimax**. Utility: `+1` win, `-1` loss, `0` draw for the maximizing player.

Default mode is **AI vs AI** (both optimal) so the program finishes without waiting for input. Optimal play yields a **DRAW**.

## How to run
```powershell
python 02_tic_tac_toe/tic_tac_toe.py
```

Human vs AI (optional):
```powershell
python 02_tic_tac_toe/tic_tac_toe.py --interactive
```

## What to screenshot
- Header `=== Tic-Tac-Toe Demo (AI vs AI, Minimax) ===`
- ASCII board after each turn
